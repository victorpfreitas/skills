# Produção IA

Skills que cobrem o fluxo inteiro de produção: validar a ideia antes de roteirizar, gerar prompts de imagem, vídeo, música e voz nos modelos que uso em produção (Nano Banana 2, Seedream 5.0 Pro, GPT Image 2, Seedance 2.0, ElevenLabs), montar os clipes num vídeo final e otimizar thumbnail/título antes de publicar.

A maioria assume que a direção da cena já foi decidida e foca em transformar essa decisão em um prompt de alta performance; `pesquisa-de-conteudo`, `montagem-prompter` e `thumbnail-titulo-otimizado` cobrem as pontas antes e depois da geração.

| Skill | O que faz |
| --- | --- |
| [`pesquisa-de-conteudo`](./pesquisa-de-conteudo) | Valida se uma ideia de vídeo tem demanda e sugere um ângulo, antes de roteirizar. |
| [`image-prompter`](./image-prompter) | Gera prompts cinematográficos de imagem e decide qual modelo usar entre Nano Banana 2, Seedream 5.0 Pro e GPT Image 2. |
| [`seedance-prompter`](./seedance-prompter) | Transforma ideia, cena ou referência visual em prompts de vídeo prontos para o Seedance 2.0. |
| [`elevenlabs-voiceover`](./elevenlabs-voiceover) | Formata roteiro em voice-over com tags emocionais do ElevenLabs Eleven v3, pronto para narração. |
| [`trilha-sonora-prompter`](./trilha-sonora-prompter) | Traduz o tom emocional de uma cena em prompt de geração de música, para trilhas separadas dos clipes de vídeo. |
| [`montagem-prompter`](./montagem-prompter) | Decide ritmo de corte, transições, sincronia com a trilha e legenda ao montar os clipes gerados num vídeo final. |
| [`thumbnail-titulo-otimizado`](./thumbnail-titulo-otimizado) | Gera e pontua thumbnail e título, fechando o loop gerar → pontuar → ajustar antes de publicar. |
