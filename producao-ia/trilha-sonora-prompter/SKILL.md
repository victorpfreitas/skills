# Soundtrack Prompter

You translate the emotional intent of a scene or video into a music-generation prompt: genre, mood, instrumentation, tempo — never a vague reference like "something epic-ish." `seedance-prompter` always declares `music: none` in the audio block of video clips (a deliberate decision to keep the soundtrack out of the video prompt), so this is the skill that closes that gap separately. The standard output of this skill is a prompt for generating the track in **Suno**. `vidiq_generate_music`, available directly in this conversation, is the alternative for when generation needs to happen without leaving the chat.

## When to use this

After the clip (or sequence of clips) has already been generated by `seedance-prompter`, or alongside the script/shot breakdown from `diretor-cinematografico`, when it's time to decide on the soundtrack. Never during the writing of the video prompt itself — music and video are generated by separate tools in this workflow.

---

## Workflow

### 1. Read the emotional intent of the scene

Before thinking about musical genre, identify what the scene needs emotionally — the same reading `diretor-cinematografico` already does for camera and light: what changes in the viewer from the start to the end of the segment, what the internal rhythm is (rising tension, relief, contemplation, urgency). If the script or shot breakdown already describes this, reuse it — don't reinvent the emotional read from scratch.

### 2. Build the style prompt (Suno's "Style of Music" field)

Read `references/SUNO.md` for the full formula. Summary: `[Genre/subgenre], [Tempo/energy/BPM], [Key instruments], [Vocal style], [Production/mood], [Modifiers]` — 4 to 8 descriptors, comma-separated (Suno reads separated tags better than a running paragraph), genre and vocal type right at the start.

### 3. Decide the structure (the "Lyrics" field, if the track has sections/lyrics)

A pure background track is usually just the style prompt + `instrumental` at the end, with the lyrics field left empty. When the piece needs marked sections (intro/build/drop, or a sung hook), use meta tags in brackets (`[Intro]`, `[Build]`, `[Chorus]`, `[Outro]`) — see the list in `references/SUNO.md`.

### 4. Exclusions — what should not be included

Unlike Seedance (where negation never works), Suno accepts limited exclusion, but with its own rules: see `references/SUNO.md` for when to use the dedicated **Exclude** field (more reliable) versus writing the exclusion at the end of the style prompt itself.

### 5. Sync with the cut rhythm (if editing has already been decided)

If a cut-rhythm reference already exists (from `montagem-prompter` or an editing decision), the track's tempo/BPM should match that rhythm — fast cuts call for a higher tempo or a crescendo, long takes call for a steadier tempo. This avoids generating a track that later doesn't fit the edit.

### 6. Deliver

Standard delivery format (ready to paste into Suno in Custom mode):

```
## Soundtrack: [scene/video name]

**Style of Music:**
[genre/subgenre], [tempo/BPM], [instruments], [vocal], [mood/production], [modifiers]

**Exclude (if applicable):**
[what to remove, dedicated field or inline at the end of the style, see SUNO.md]

**Lyrics (if applicable):**
[structure meta tags + lyrics, or "instrumental" if there are none]
```

### Alternative — generate directly in the conversation via vidIQ

If the user asks to generate the audio without leaving the chat (instead of taking the prompt to Suno), use `vidiq_generate_music`:
- Build the prompt in the same order — genre + mood + instrumentation + tempo + vocal — but **never use negation** here: unlike Suno, `vidiq_generate_music` does not support negative phrasing ("no drums") at all; describe only what you want, and add "instrumental" when no vocal is wanted.
- `durationSeconds` (10-180) is approximate — the tool is asynchronous (`mcpJobId`), poll with `vidiq_job_poll` until `completed` to get the real duration and download link.
- If the provider's safety filter blocks the prompt, this is common even for harmless requests — suggest ONE rephrasing and wait for the user's confirmation before trying again.

---

## Critical rules

- Never write the music prompt by only looking at the video's theme — the emotional read of the scene comes first, the genre is a consequence of it, not the starting point.
- Suno and vidIQ handle negation differently — don't mix one tool's rule with the other's (see `references/SUNO.md` for Suno's details; vidIQ never accepts negation).
- One track per video/sequence, unless the user explicitly asks for variation by block (e.g., intro vs. body vs. CTA).
- Always deliver either a ready-to-paste prompt (for Suno) or poll the job until `completed` before delivering the link (for vidIQ) — never promise the audio before confirming it's finished.
