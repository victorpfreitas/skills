# Reference Director Styles

When the user asks for "the style of [director]", apply the full system: lens + camera + lighting + color + composition + vibe. Each profile is a coherent visual package — don't mix elements randomly.

---

## David Fincher

- **Lenses**: 27–50mm, rarely aggressively wide
- **Camera**: Almost always static or with minimal movement, precise, controlled. Imperceptible dolly, ghost steadicam
- **Lighting**: Low-key, deep black, single cold light source. Cold backlight that separates the subject from the background
- **Color**: Desaturated, green-gray, teal and amber. Controlled highlights
- **Composition**: Central or strict rule of thirds. Character centered in the frame, environment around them
- **Performance**: Restrained actors. Internal emotion, not expressed. The face reveals the bare minimum

> **Vibe**: Surveillance. The camera observes before it judges. The viewer knows more than the character.

**Key prompt elements**:
```
LENS: 35mm prime. Cold, controlled single-source backlight.
CAMERA: Near-static, barely perceptible slow push. No shake.
COLOR: Desaturated. Teal-green shadows, amber highlights. Deep blacks.
PERFORMANCE: Contained. Internal emotion. Face reveals minimum.
```

## Denis Villeneuve

- **Lenses**: Wide (24–35mm) with enormous depth of field
- **Camera**: Slow, majestic movements with weight. Crane-ups that reveal scale. Never rushed
- **Lighting**: Natural, diffused, epic scale. Window light, open sky, fog
- **Color**: Monochromatic palettes per film — orange in *Dune*, gray in *Arrival*, teal in *Blade Runner 2049*
- **Composition**: Small human figure in immense spaces. Architecture dominates the frame
- **Performance**: Actors in a state of contemplation. Silence as dialogue

> **Vibe**: The universe is vast and the human being is fragile within it. Grandeur that overwhelms gently.

**Key prompt elements**:
```
LENS: 28mm wide. Vast depth of field. Diffused natural light.
CAMERA: Slow crane or slow dolly — weighted, majestic movement.
COLOR: Monochromatic palette — [pick dominant hue for scene].
FRAMING: Human figure small against massive architecture or landscape.
```

## Park Chan-wook

- **Lenses**: Compressive telephoto (85–200mm) + extreme close-ups that invade the character's space
- **Camera**: Static alternating with sudden, precise movements. Occasional zoom used as punctuation
- **Lighting**: Bi-color. Warm and cold in tension within the same scene. Red as blood and desire
- **Color**: Saturated palette, red and blue as an emotional code. Skin against primary colors
- **Composition**: Broken symmetry. Character at the edge of the frame, about to leave. Foreground blocking
- **Performance**: Elegant restraint that precedes explosion. Beauty as a warning sign of violence

> **Vibe**: Beauty that hurts. Elegance that foreshadows. The perfect frame contains something rotten.

**Key prompt elements**:
```
LENS: 135mm telephoto. Compressed space. Two-tone light: warm source left, cold source right.
CAMERA: Static. Precise. Then sudden precise reframe.
COLOR: Saturated. Red and blue as emotional code. High contrast.
FRAMING: Near-symmetrical but broken — subject at edge of frame.
```

## Roger Deakins (DP)

- **Lenses**: 32–65mm, prefers primes. Never an extreme focal length without narrative reason
- **Camera**: Motivated by the character. Never arbitrary. Moves when the character moves
- **Lighting**: Backlight as a signature. Rim lights. Silhouettes against luminous backgrounds. One main source
- **Color**: Coherent, restrained palette per scene. Each environment has a single dominant tone
- **Composition**: Clear geometry, foreground always intentional. Nothing in the background by accident

> **Vibe**: Clarity with depth. Beauty that doesn't call attention to itself. You forget there's a camera there.

**Key prompt elements**:
```
LENS: 40mm or 50mm prime. Single strong backlight / rim light.
CAMERA: Moves only when character moves. Motivated always.
COLOR: Restricted palette — one dominant hue per location.
COMPOSITION: Clean geometry. Deliberate foreground element.
```

## Emmanuel Lubezki (Chivo)

- **Lenses**: Extreme wide (14–21mm), intentional distortion at the limit
- **Camera**: Fluid handheld, long unbroken takes. Camera inside the action, not observing from outside
- **Lighting**: Natural light only. Golden hour as religion. Underexposed to preserve the sky
- **Color**: Warm skin tones, organic green, open sky. No artificial color correction
- **Composition**: Camera within the character's body — action all around, not at a distance

> **Vibe**: You're inside the character's body, not watching. Total immersion. The world breathes.

**Key prompt elements**:
```
LENS: 18mm wide. Natural light only — golden hour preferred.
CAMERA: FLUID HANDHELD. Long take. Camera inside the action.
COLOR: Warm skin tones, organic greens. No correction.
FRAMING: Subject surrounded by action — camera participates.
```

## Michel Gondry

- **Lenses**: 28–35mm with heavy bokeh in close shots. Analog wide for panoramas
- **Camera**: Handheld with a soul — not nervous, but curious. Moves that feel handmade, not machine-made
- **Lighting**: Domestic practicals: ordinary lamps, table lamps, TV light. Warm and gritty. Zero studio
- **Color**: Saturated but aged primary colors — like a Polaroid or faded Super 8. Nursery blue, heartbreak red
- **Composition**: Physical objects as visual protagonists. Handmade mechanisms in frame. Camera that witnesses, doesn't perform
- **VFX / Tricks**: In-camera, handcrafted, intentionally lo-fi. Stop motion, projections, visible miniatures. The trick being visibly a trick is part of the poetry
- **Performance**: Melancholy that doesn't cry. Characters daydreaming. Body in the real world, mind elsewhere

> **Vibe**: Affective memory turned into image. Objects that hold emotions. The impossible made by hand, with warehouse care.

**Key prompt elements**:
```
LENS: 32mm prime. Practical domestic lights — table lamp, TV glow.
CAMERA: HANDHELD but curious, not nervous. Slow, wondering movement.
COLOR: Saturated but aged — faded Polaroid palette. Warm domestic grain.
COMPOSITION: Handmade physical object in frame. Mechanism visible.
PERFORMANCE: Daydreaming stillness. Body present, mind elsewhere.
```

## Christopher Doyle (Wong Kar-wai films)

- **Lenses**: 28–35mm with heavy bokeh
- **Camera**: Erratic handheld, step-printing (strobe-like slow motion), overcranked
- **Lighting**: Urban neon, practicals, color blur. Never clean
- **Color**: Oversaturation, warm Hong Kong grades. Neon yellow, red, green
- **Composition**: Intentional blur, frame within a frame, reflections in glass

> **Vibe**: Emotional memory. The past leaking into the present. Time as texture, not as a line.

**Key prompt elements**:
```
LENS: 28mm with heavy bokeh. Neon practical lights — no fill.
CAMERA: ERRATIC HANDHELD. Step-printing / overcranked stutter.
COLOR: Oversaturated. Neon yellows, reds, greens. Hong Kong grade.
COMPOSITION: Intentional blur, reflections, frames within frames.
```
